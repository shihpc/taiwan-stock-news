Cloudflare 自曝 AI 服務跨租戶外洩 155 筆回應｜Cloudflare 10/26 發布事故報告，承認 Workers AI 的 GLM-5.3 模型在 2026/8/27–9/9 有 155 筆回應夾帶其他客戶先前 prompt 的內容。根因是模型宣告 104.8 萬 token 上下文、但 prefill GPU 的 KV cache pool 只容得下 68.1 萬，超長請求未被中止，decode 端讀到前一筆殘留的 cache 分頁；受影響回應的 prompt 都超過 68.1 萬 token。

【對從業的意義】這是多租戶推論的隔離失效、不是提示注入——使用者端無從察覺，照樣回 200。防護動作：盤點有沒有把客戶資料丟進共用 LLM 端點的超長 prompt，敏感長上下文改走專用部署；供應商審查要求揭露租戶隔離測試方式——Cloudflare 自承原本只驗回應碼與效能、沒驗輸出內容。
