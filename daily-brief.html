把惡意指示檔丟進你的「下載」資料夾，就能劫持 AI 編碼助理｜資安公司 Forever Security 在客戶的下載資料夾發現偽裝成工程筆記的惡意 AGENTS.md，誘使在該資料夾啟動的編碼代理去裝惡意套件。實測一套代理在逾 90% 的嘗試中照做，手法是改寫機器層級設定檔、常駐新增一個外部服務；對另一套植入指示要求把 API 端點指向攻擊者伺服器，約半數照做、約五分之一在同一 session 內就取得程式執行。其遙測稱約半數客戶在下載資料夾裡跑代理。

【對從業的意義】這不是原廠能修補的漏洞——代理讀取所在資料夾的指示檔本來就是設計行為。今天兩件事：規定不在下載資料夾啟動 AI 代理，並檢查代理設定檔有無被改過的 API 端點。
